Recommended path

New to Mneme? Start by installing it and activating one protection. Then write enforceable ADRs, and add enforcement where your agents work and where changes merge. Steps 1 to 4 build on the same ADR-012 example, so you can follow them in order without resetting your project.

Already partway through? If your ADR is imported, jump to agent enforcement in step 2 or task-specific retrieval in step 3. If local checks already pass, go straight to the pull-request gate in step 4.

Start here · CLI Install Mneme and activate your first protection Run setup, import an ADR, let the audit find a Mneme-ready decision, then validate and activate its rule. Step 1 · CLI Turn an ADR into an enforceable decision Add a Constraints section, import the ADR, and get a FAIL when a handler imports the database client. Step 2 · Claude Code Stop an AI coding agent from crossing an architectural boundary Block a forbidden import before Claude Code writes it, and tell the agent which decision it broke. Step 3 · Claude Code, MCP Give coding agents the decisions that apply to a task Look up the ADRs for the file an agent is editing, from the CLI or the MCP server. Step 4 · GitHub Actions Fail a pull request that breaks an ADR Run mneme check on every changed file and keep the JSON verdicts.
