Pricing · Open Source and Enterprise

One open decision engine. Two ways to govern engineering decisions.

Mneme’s open-source engine runs inside each repository and enforces the engineering decisions your team has recorded as rules. Enterprise is our direction for governing those decisions across an organization: finding them across systems, reconciling who decides, and keeping them current across teams.

The engine is free under the MIT License. There is no paid tier today.

  • Available today released and usable now
  • Enterprise direction not built or sold yet; shaped with design partners

The decision engine, run independently in each repository. Install it and use it without talking to us.

  • Decision Index: each decision’s versions, lifecycle and source, kept in the repository
  • Applicability: a rule applies across the repository or only to the paths it names
  • Authority: agents can propose a decision; only a person using the command-line tool accepts it
  • Precedence: supersession, then priority and date between decisions in the same scope
  • Deterministic enforcement: pre-write checks in supported agents and a CI gate in each repository; it blocks only in strict mode
  • Local evidence: each violation names the decision and the rule that fired

Where Open Source ends and Enterprise begins

Open Source executes known decisions, one repository at a time. Enterprise is the direction for running engineering decision governance at organizational scale. Every cell in the Enterprise column is a direction, not a feature you can buy today.

Dimension Open Source Available today Enterprise Enterprise direction
Purpose Enforce known decisions that have active rules, in each repository Find, reconcile and govern decisions across the organization
Decision Index Versions, lifecycle and source for every decision, in project_memory.json. It records no approver identity. Built on the same open Decision Index
Authority, applicability, precedence A person accepts decisions; rules can be limited to paths; same-scope priority, then date Governed workflows for who decides, across teams
Deterministic enforcement Pre-write checks in each supported agent and a CI gate in each repository. Strict mode blocks; warn mode reports. Managed across teams and environments
CI across many repositories Add the gate to each repository; every repository runs its own check One place to manage the gate across repositories
Agent integrations Set up per repository, each with a documented support level Central management
Decision discovery ADRs imported from files in the repository Across systems
Confluence, Jira, Slack Not supported: no import path exists Confluence ADR ingestion is planned. Jira and Slack are ideas only, with no scheduled work.
Evidence Local and inspectable: verdicts in the terminal and CI job log Aggregated history and reporting
Administration Local files in the repository Role-based access, approvals, lifecycle

Frequently asked questions

Can we buy Mneme Enterprise today?

No. There is no paid Enterprise tier, and nothing in the Enterprise column ships today. We are shaping it with design partners. Today, an organization can run the open-source engine in each repository and apply for the complimentary guided pilot.

Can the open-source engine gate CI across many repositories?

Yes, one repository at a time. Each repository runs its own mneme check job in CI. In warn mode the job reports findings and passes; in strict mode a violation fails it. What Open Source does not give you is one place to manage that gate across repositories. See CI governance for AI-generated code.

Is the core engine free and open source?

Yes. The engine, the command-line tool (mneme-hq), the agent hooks, the Decision Index and the precedence rules are open source under the MIT License. You can read the code and install it from GitHub.

Who qualifies for the Guided Pilot?

Engineering teams using AI coding tools (Claude Code, Cursor, GitHub Copilot or agent workflows) that already have ADRs, repository rules or engineering standards to enforce. Submit a pilot request to discuss your setup.

Does the open-source engine run on our own infrastructure?

Yes. It runs on developer machines and in your CI pipelines, and it does not send source code or decision files to Mneme. The hosted Architecture Audit is separate; Security & Data Handling covers what it receives.
