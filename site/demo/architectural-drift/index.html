Runnable demo RUNS LOCALLY AGENTS SCRIPTED

Preventing architectural drift from AI coding agents.

Three agents work across a week. Every change is locally reasonable, and the architecture still drifts, because each one quietly relaxes an invariant the team already encoded. Mneme fails the first divergence before the rest are built on top of it.

By Theo Valmis · Published May 2026 · All demos

The decisions at stake
→ ADR-001 prohibits external databases. Redis is forbidden.
→ ADR-004 requires all persistence to go through a Repository abstraction.

The demo shows how three agents accidentally violate these decisions over a week — and how Mneme fails the first divergence before it propagates.

mneme-demo — bash
$ 
Full terminal transcript 
$ mneme check --input agent_a_redis_cache.txt --query "storage backend" --mode warn

↳ Agent A -- Monday: "speed up the user lookup endpoint"

Diff:
  import redis
  _cache = redis.Redis(host="localhost", port=6379)

FAIL  [ADR-001] anti_pattern "redis-py" -- trigger: redis
      JSON storage only -- no external database.
WARN  [ADR-001] constraint "no redis" -- trigger: redis
      JSON storage only -- no external database.

Result: FAIL

What happened

  • Agent A proposed a Redis cache. ADR-001 forbids external databases, so the check returned FAIL.
  • A second, corrected file using the existing JSON cache module was checked independently and passed.
  • Agent B, working from the corrected codebase, produced a compliant diff that also passed — a fourth check confirms Agent B's original Redis-based approach would have returned the same FAIL.

Run it yourself

git clone https://github.com/MnemeHQ/mneme
cd mneme/examples/architectural-drift
python run.py

Step 1 is the first divergence. It prints exactly this:

FAIL  [ADR-001] anti_pattern "redis-py" -- trigger: redis
WARN  [ADR-001] constraint "no redis" -- trigger: redis

Result: FAIL

The agents are scripted so the enforcement output stays deterministic — no LLM call is involved. The script runs in warn mode, which always exits 0; a strict-mode CI gate maps this same FAIL to a non-zero exit and blocks the merge.
