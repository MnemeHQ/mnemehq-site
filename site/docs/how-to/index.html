Docs · How-to guides

How-to guides

Each guide solves one engineering job. Every output shown is recorded from mneme-hq 0.9.2, and CI replays those steps on every change to the guides. Steps that need your own setup, such as starting Claude Code, are marked and not replayed.

Make decisions enforceable

How-to · CLI Turn an ADR into an enforceable decision Add a Constraints section, import the ADR, and get a FAIL when a handler imports the database client. Guide · CLI Activate protection for a Mneme-ready decision List, validate and activate the guardrail the audit proposes for an existing decision.

Reach your coding agents

How-to · Claude Code Stop an AI coding agent from crossing an architectural boundary Block a forbidden import before Claude Code writes it, and tell the agent which decision it broke. How-to · Claude Code, MCP Give coding agents the decisions that apply to a task Look up the ADRs for the file an agent is editing, from the CLI or the MCP server. Guide · CLI, MCP Review decisions an agent proposes Agents propose over MCP; people accept or reject with the CLI.

Gate changes at merge

How-to · GitHub Actions Fail a pull request that breaks an ADR Run mneme check on every changed file and keep the JSON verdicts.

Other kinds of docs

How-to guides assume you know what you want to do. To learn how Mneme decides, read how enforcement works and the decision model. To look up a flag or a tool, use the CLI reference and the MCP server reference. For a first run with nothing set up, start with the quickstart.
