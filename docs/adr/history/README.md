# Historical website ADRs

This directory mirrors the seven website ADRs originally authored in
`MnemeHQ/mneme`. The originals remain in the core repository as immutable
historical records, as required by core ADR-016. These copies are retained
locally so website contributors can inspect the full provenance without
switching repositories.

Every ADR in this directory remains `superseded`; none is part of this
repository's active compiled constraint set. Current publishing and deployment
rules live in [`PUBLISHING.md`](../../../PUBLISHING.md). Active site-repository
ADRs are direct children of [`docs/adr/`](../) and are compiled into
`.mneme/project_memory.json`.

Mirrored records:

- ADR-003: Site Publishing Guidelines
- ADR-006: Insights Article SEO and Schema Requirements
- ADR-007: OG Image Generation for Social Sharing
- ADR-008: Persona / Buyer-Page Content Standards
- ADR-011: Knowledge-graph Content Architecture
- ADR-012: Conceptual-authority Discipline
- ADR-015: Report-Anchored Insight Titles
